# BaFuse project overview

BaFuse estimates one SoH percentage for the same reference performance test (RPT) as the input. CNN-3M is the original reference architecture. The four 2M models compare architectures under the measured Discharge and Charge contract. PyDMA provides separate fit-derived degradation estimates. RAG explains available results and evidence.

The study evaluates generalization to Part 3 cells and measurement protocols. It does not establish future forecasting, remaining useful life, or accuracy in operation.
